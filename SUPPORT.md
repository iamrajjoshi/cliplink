# Getting help

Start with the [quick start](README.md#quick-start) or the [CLI troubleshooting guide](docs/cli.md#troubleshooting). For your collection's appearance or GitHub Pages setup, use the [template guide](https://github.com/iamrajjoshi/cliplink-template#quick-start).

If you're still stuck, [open an issue](https://github.com/iamrajjoshi/cliplink/issues/new/choose). This repository covers the CLI, shared schema, and Cliplink landing page. Questions are welcome too; choose a blank issue if the bug and feature forms don't fit.

For a command that fails, include:

- Your CLI version (`clip --version`) and Node.js version (`node --version`).
- Your operating system and whether you used GitHub API publishing or `--local`.
- The command and a small example, with private URLs and content replaced by placeholders.
- What you expected and what happened, including relevant error output.

Never include tokens or credentials. For suspected vulnerabilities, follow the [private reporting instructions](SECURITY.md) instead of opening an issue.

Contributions and fixes go through [Contributing](CONTRIBUTING.md). Cliplink is a maintainer-run project; response times vary.
